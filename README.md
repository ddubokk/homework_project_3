# Виджет банковских операций

Учебный Python-проект для безопасной работы с банковскими данными. Программа скрывает часть цифр в номерах карт и счетов, чтобы защитить конфиденциальную информацию пользователя.

## Технологии
- **Python 3.11+**
- **Poetry** — управление зависимостями и виртуальным окружением
- **Flake8** и **Mypy** — проверка стиля кода и типов
- **Pytest** — написание тестов

## Установка и запуск

1. Склонируй репозиторий к себе на компьютер:
```bash
git clone git@github.com:ddubokk/homework_project_3.git
cd homework_project_3
```

2. Установи зависимости через Poetry:
```bash
poetry install
```

3. Запусти главный файл для проверки работы функций:
```bash
poetry run python -m src.main
```

## Примеры работы

В модуле `src/masks.py` реализованы две основные функции:

```python
from src.masks import get_mask_account, get_mask_card_number

# Маскировка карты (остаются первые 6 и последние 4 цифры)
print(get_mask_card_number("7000792289606361"))
# Вывод: 7000 79** **** 6361

# Маскировка счета (остаются только последние 4 цифры)
print(get_mask_account("73654108430135874305"))
# Вывод: **4305
```

## Проверка кода и тесты

Чтобы проверить код линтерами на соответствие PEP 8 и правильность типов:
```bash
poetry run flake8 src
poetry run mypy src
```

Запуск юнит-тестов:
```bash
poetry run pytest
```
